# Bible New Tab ✝️

إضافة بسيطة واحترافية لـ Chrome وBrave تعرض آية كتاب مقدس جديدة مع كل تبويب جديد.

## المميزات
- آية عشوائية محلية بدون API أو تسجيل دخول.
- بطاقة آية أنيقة فوق مربع البحث.
- زر **آية أخرى** لتغيير الآية يدويًا.
- الضغط على **Space** يغيّر الآية.
- بحث Google مباشر.
- تصميم عربي RTL ومتجاوب.
- دعم الوضع الفاتح والداكن تلقائيًا.
- تعمل بدون إنترنت بعد تحميل الإضافة، باستثناء تحميل الخطوط من Google Fonts عند توفر الإنترنت.

## التثبيت على Brave أو Chrome
1. حمّل ملفات الريبو أو استخدم **Code → Download ZIP**.
2. افتح صفحة الإضافات:
   - Brave: `brave://extensions`
   - Chrome: `chrome://extensions`
3. فعّل **Developer mode / وضع المطوّر**.
4. اختر **Load unpacked / تحميل غير مضغوط**.
5. اختر مجلد `Bible-New-Tab`.
6. افتح تبويبًا جديدًا وستظهر الآية فوق مربع البحث.

> ملاحظة: لأن الإضافة تستبدل صفحة التبويب الجديد، لن تظهر صفحة التبويب الافتراضية للمتصفح أثناء تفعيلها.
